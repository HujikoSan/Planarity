# Planarity Game

## ルール説明

このゲームの目的は、ランダムに生成されたグラフの頂点（点）を移動させ、辺（頂点同士を結ぶ線）が互いに交差しないように配置することです。

## 各画面の説明

### 入力画面

*   **目的**: ゲームを開始するにあたり、グラフの頂点数を指定します。
*   **入力フィールド**: ここに希望する頂点の数を入力します（3から40の間）。
*   **スタートボタン**: 入力フィールドに数を指定した後、このボタンをクリックするとゲームが開始されます。

### ゲーム画面

*   **メインゲームエリア**: ここにグラフが表示され、操作を行います。
*   **頂点（点）**: ドラッグして移動できる丸い点です。
*   **辺（線）**: 頂点同士を結ぶ線です。
*   **辺の色の意味**:
    *   <font color='red'>赤色の辺</font>: 他の辺と交差していることを示します。
    *   <font color='green'>緑色の辺</font>: 他の辺と交差していないことを示します。

### クリア画面

ゲームをクリア（全ての辺が交差していない状態に）すると表示されます。

*   **「You Win!」メッセージ**: クリアしたことを示します。
*   **統計情報**: クリアにかかった頂点数、辺の数、経過時間が表示されます。
*   **ボタン群**:
    *   **New Game**: 新しいゲームを開始します（入力画面に戻ります）。
    *   **Retry Same Level**: 同じ頂点数・辺の配置で再度挑戦します。
    *   **Capture View**: クリアした盤面のスクリーンショットをクリップボードにコピーします。
    *   **Post to X**: クリア時の盤面をX（旧Twitter）に投稿するための画面を開きます（投稿内容は自動生成されます）。

### ポーズメニュー

ゲーム中に右クリックすると表示されます。

*   **Resume**: ゲームを再開します。
*   **Reset Level**: 現在のレベル（同じ頂点数・辺の配置）を最初からやり直します。
*   **Quit to Menu**: ゲームを終了し、入力画面に戻ります。

## 操作説明

### 入力画面での操作

1.  テキストボックスに、ゲームで使用したい頂点の数（3から40の整数）を入力します。
2.  「Start」ボタンをクリックすると、ゲーム画面に遷移します。

### ゲーム画面での操作

*   **頂点の移動**: 解消したい交差に応じて、マウスの左ボタンで頂点をクリックしたままドラッグし、任意の位置でボタンを離すと頂点が移動します。
*   **ポーズメニューの表示**: ゲーム画面内でマウスの右ボタンをクリックすると、ポーズメニューが表示されます。
*   **ウィンドウのサイズ変更**: ゲームウィンドウの境界をドラッグすることで、ウィンドウサイズを変更できます。グラフの要素は新しいウィンドウサイズに合わせて自動的に調整されます。

### クリア画面での操作

表示された各ボタン（「New Game」、「Retry Same Level」、「Capture View」、「Post to X」）をマウスの左ボタンでクリックすることで、それぞれの機能を利用できます。

### ポーズメニューでの操作

表示された各オプション（「Resume」、「Reset Level」、「Quit to Menu」）をマウスの左ボタンでクリックすることで、それぞれの操作を実行できます。

## 導入方法（実行方法）

### 必要なもの

このゲームを実行するには、Pythonといくつかライブラリが必要です。

*   **Python 3**: [Python公式サイト](https://www.python.org/) からダウンロードしてインストールしてください。
*   **Pygame**: グラフィックとサウンドのライブラリです。
*   **Pillow**: 画像処理ライブラリです（スクリーンショット機能で使用）。
*   **pywin32**: Windows APIをPythonから利用するためのライブラリです（Windowsでのクリップボード機能で使用）。

### ライブラリのインストール方法

Pythonをインストールした後、コマンドプロンプトまたはターミナルを開き、以下のコマンドを実行して必要なライブラリをインストールします。

```bash
pip install pygame Pillow pywin32
```

*注意: pywin32 は Windows 専用です。他のOSではクリップボードへのコピー機能が動作しない場合がありますが、ゲームの主要な機能はプレイ可能です。*

### ゲームの実行方法

1.  このリポジトリのファイル（`planarity.py` と `test_planarity.py`）をコンピュータの任意のフォルダにダウンロードまたはクローンします。
2.  コマンドプロンプトまたはターミナルで、これらのファイルを保存したフォルダに移動します。
3.  以下のコマンドを実行してゲームを開始します。

```bash
python planarity.py
```

## その他

*   **グラフ生成**: ゲーム内で表示されるグラフは、指定された頂点数に基づいてランダムな平面的グラフ（※）として生成されます。辺の数や配置もランダム性を含みます。
    *   ※平面的グラフとは、辺が互いに交差することなく平面上に描画できるグラフのことです。ゲームの開始時は交差していることがありますが、必ず交差を解消できる配置が存在します。
*   **スクリーンショット機能**: ゲームクリア時に「Capture View」ボタンを使用すると、現在のゲーム画面が画像としてクリップボードにコピーされます（Windows環境）。これにより、簡単にクリア画面を保存・共有できます。
*   **テストファイル**: `test_planarity.py` は、グラフの交差判定ロジックなど、ゲームのコア機能に関する基本的なユニットテストを含んでいます。
